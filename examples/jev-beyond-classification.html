What Jev can do beyond classification

Jev answers typed questions about text for $0.042 per million input tokens, in a few hundred milliseconds, and returns the full probability distribution. That price and speed support designs a chat model makes too slow or too costly: scoring every opinion in a universe instead of a sample, mapping where in an opinion an issue is decided, debugging a taxonomy from its own confusions, gating an agent at every step.

Patterns from Rebecca Fordon’s experiments, TypeSafe’s docs and the Jev communityNumbers are measured; untried ideas are marked

§01  Four levers

Every pattern combines the same four properties

Jev is not a chat model: it cannot write, explain, cite or retrieve. It reads a state and answers named questions with probabilities. Read each pattern below as an answer to one question: which of these four properties is it exploiting?

Nearly free
$0.042 / M
Input tokens; output is free. Unlocks: asking every document, every wording, every question you might need. 1,067 citing cases screened for $0.092.
Fast
0.1–0.4 s
Per request, many questions included. Unlocks: live feedback, per-step agent gates, control loops. 0.37 s per claim against 26–41 s for Opus.
Distributions
p, not a label
Every option’s probability comes back. Unlocks: two-threshold gates, uncertainty as a signal, disagreement, features for other models.
Many at once
N questions, 2+ texts
Named questions run in parallel; state can be an array. Unlocks: profiles, decision trees, pairwise judgments. 13 questions over a 54k-character document in 0.27 s.
Choice
Picks one of up to 255 options; probabilities sum to 1, so always add none. Leans toward the first option.
Score
2 to 10 ordered levels; returns a probability-weighted position. For gates, read the top level’s probability, not the expectation.
Noul
P(yes). No confidence field; 0.5 means unsure. The absolute check that a relative Choice lacks.

§03  Funnel

Jev is reliable at the ends and mushy in the middle

Distributions Nearly free

In the citation-checker runs, every claim scored 0.95 or above was supported and none under 0.50 was, while “partially supported” claims spread across the middle. So the useful design has two thresholds: clear above one, flag below the other, and send the band between them on. Move the thresholds and watch what slips through. Then switch to a vaguer question.

§04  Heat map

Jev cannot cite, but it can point at what you number

Many at once Nearly free Fast

Ask the same question of every paragraph and the answers form a map of the opinion. A Noul per paragraph gives absolute heat, which blurs “mentions the issue” into “decides it.” A Choice across all paragraphs gives a relative locator, which is sharper. Click any sentence to delete it and re-ask: the sentences whose removal moves the answer are what drove it.

    §06  Where it breaks

    Failure modes, with the fix that worked

    FailureWhat happenedWhat worked
    Literal readingA one-of-N Choice picked “plaintiff” when the true answer was “both” (district-court probe). TypeSafe lists indirection and double negatives as weak spots.Ask the decision as one plain yes/no; write the boundaries into the criteria.
    Your facts in the questionA generic on-issue question with the researcher’s facts embedded scored anchor cases 0.03–0.25.A neutral doctrinal question separated 0.90 from 0.15.
    Long, noisy stateTypeSafe calls it context rot. In CaseCloud, 60 of 117 documents hit the 9,000-character window cap, which became the ceiling.Send located passages or citation-context windows, not whole opinions.
    Calibration off its home turfA fair die came up 1 about 83% of the time; contested items read overconfident. On unseen legal material, Choice and Score ran overconfident and Noul underconfident.Fit thresholds per question on your own labels; never use the vendor’s bands as-is.
    Fabrication blindnessA fabricated quote scored 0.99 “supported,” because the proposition itself was true.Run quote, citation and pincite checks in code before Jev sees the claim.
    Arithmetic, dates, countsOn TypeSafe’s own jaggedness list for 1.13.Do them in code; ask Jev only for the parts, as in the date cookbook.
    Choice orderLeans toward the first option.Shuffle or ask in both orders when it matters.
    Vague questions“Did the summary leave anything out?” scored 0.78–0.90 on every claim.Atomic questions, combined in code with max for flags.
    Hard reasoning as the final wordChess, and code review as the only reviewer, both failed in the field.Use Jev for triage and gates; keep the decision with an LLM or a person.
    Speed and cost hypeField measurements put it 5–7× faster than small LLMs, not 200×. Batched offline LLM prompts can match its cost. A Jev locator feeding Opus saved at best 36%; the Batches API saves 50%.Price the best case before building.
